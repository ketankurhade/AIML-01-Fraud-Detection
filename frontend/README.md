# Fraud Analyst UI (Vue 3 + Vite)

Modern, reactive single-page dashboard designed for fraud operations analysts and risk engineers.

## Core Views
- **Live Stream Ticker**: Real-time incoming transactions with color-coded risk scores (Low, Medium, Critical).
- **Fraud Graph Explorer**: Interactive node-link visualization showing cyclic fraud rings, mule accounts, and payment flows.
- **Model Drift & Metrics View**: Live Evidently AI drift metrics, throughput graphs, and alert statistics.
- **Transaction Inspection Panel**: Deep-dive audit view displaying Feast feature values, balance shifts, and model explanation factors.
